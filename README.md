# LaporPak

LaporPak adalah conversational public-service gateway berbasis WhatsApp
untuk mendukung layanan dan pengaduan masyarakat desa.

## Tech Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui

### Backend

- FastAPI
- Python
- Pydantic

### Development Requirements

- Git
- Node.js LTS
- npm
- uv
- Python 3.12
